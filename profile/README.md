# Monosnap Screen Capture

**Monosnap Screen Capture** is a fast and lightweight screenshot and screen recording application for Windows and Mac. As a powerful **Monosnap Annotation Tool**, you can add arrows, rectangles, circles, text labels, blur effects, and numbered steps to your screenshots instantly. This **Monosnap Cloud Uploader** integrates with Google Drive, Dropbox, Amazon S3, and custom FTP servers for automatic sharing. With **Monosnap Video Recorder**, you can capture screen activity, webcam video, and microphone audio in MP4 format.

## Features

- **Multiple Capture Modes**: The **Monosnap Screen Capture** supports full screen, selected region, and active window.

- **Auto Upload**: As a **Monosnap Cloud Uploader**, it generates shareable links with one click.
- **Recording Options**: This **Monosnap Video Recorder** includes webcam overlay and push-to-talk.
